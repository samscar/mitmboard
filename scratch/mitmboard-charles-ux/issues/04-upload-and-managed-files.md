# 04 — 上传文件与托管文件清理

**What to build:** 规则对话框的文件来源增加「上传文件…」，用户在浏览器里选本机文件，上传后映射生效，场景 B（云主机）也能用。托管目录有明确的生命周期：内容哈希命名、相同内容去重、单文件上限 20 MB、保存规则时清理不再被任何规则引用的托管文件，手输的托管目录之外的路径永远不动。

**Spec:** ../spec.md

**Blocked by:** 02 — 右键请求行建 Map Local（使用已捕获的响应）

**Status:** ready-for-agent

- [ ] 上传后规则指向托管目录中的文件，请求返回该文件内容
- [ ] 重复上传同一内容只保留一份
- [ ] 超过 20 MB 被拒绝（422），提示改用手输路径
- [ ] 删除或修改规则并保存后，无引用的托管文件被清理；手输路径的文件不被清理
- [ ] 扩展名正确，Content-Type 不退化为 octet-stream
- [ ] 后端 API 测试与前端 `App` 级测试覆盖
