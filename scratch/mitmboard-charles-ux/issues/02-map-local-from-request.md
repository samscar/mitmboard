# 02 — 右键请求行建 Map Local（使用已捕获的响应）

**What to build:** 用户在一条已捕获的请求上右键，选「Map Local…」，看到预填好的规则对话框，保存后再次发起同一请求，返回的就是本地文件而不是真实响应。这是贯穿后端与前端的第一条完整闭环：右键菜单骨架、规则对话框、「把已捕获的响应存成文件」接口、托管目录、规则保存。

对话框字段：host、path、method、状态码（默认取已捕获响应的状态码）、一个可编辑的「文件路径」字段，并提示「query 参数不参与匹配」。本票只接通「使用已捕获的响应」这个便捷按钮——它把响应存成托管文件后把路径回填进字段；手输路径与「选择文件…」由票 04 补齐。请求行预填：精确 host、精确 path（去掉 query）、该请求的 method。新规则插到规则列表最前。详情页保留一个不依赖右键的 Map Local 按钮作为备用入口。
