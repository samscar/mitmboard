# Triage 标签映射

各个 skill 以五个固定的 triage 角色表述。本文件把角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 角色（mattpocock/skills） | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当 skill 提到某个角色（例如「打上 AFK-ready 标签」）时，使用本表右列对应的标签字符串。

若将来更换追踪器并改用了别的标签名，直接改右列即可。
